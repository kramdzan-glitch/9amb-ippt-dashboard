9AMB IPPT SCORING DASHBOARD - Version 10 PWA

This version adds installable mobile-app behaviour.

New files:
- manifest.json
- service-worker.js
- icons/icon-192.png
- icons/icon-512.png

How to test locally:
1. Open index.html as usual.
2. The dashboard should still work.

Important:
PWA install usually works best after hosting online using HTTPS.
Recommended hosting:
- GitHub Pages
- Netlify
- Vercel

Once hosted:
Android Chrome:
1. Open the hosted app link.
2. Tap the 3-dot menu.
3. Tap Add to Home screen / Install app.

iPhone Safari:
1. Open the hosted app link.
2. Tap Share.
3. Tap Add to Home Screen.

Google Sheet live settings:
- Edit config.js if the IPPT Entry gid changes.
